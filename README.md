# Alchemists & Architects

## About

A successfully delivered **production website for an international client**, **Alchemists & Architects**, a Seattle-based luxury salon. The project was developed to give the business a polished online presence that communicates its brand, showcases hair, beauty, and wellness services, and makes it easy for customers to move from discovery to booking.

The website combines a **responsive multi-page layout, service presentation, visual brand storytelling, customer-facing navigation, online booking access, mobile-friendly design, and production deployment**. It was built and refined for an actual client rather than as a classroom-only prototype, making it one of my real-world web-development projects.

The project demonstrates the full process of turning a client-facing design into a usable live website: organizing content, refining visual hierarchy, adapting layouts for different screen sizes, integrating service and booking paths, testing the customer experience, and delivering the finished site for production use.

## Core features

- Live production website for an international client
- Responsive desktop, tablet, and mobile layouts

- Hair, beauty, and wellness service presentation
